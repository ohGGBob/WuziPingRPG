# 天工studio

仓库里现在有两样可以装到手机上的东西：原来的离线像素 RPG，以及手机工作台「天工」。上课模式和离线 Python 写在 [天工使用与安装说明](studio/README.md)。

## 0.2.7：残灯渡剧情与美术升级

源码版本 **0.2.7**（versionCode 39），合并 0.1.24 的课堂录音改进、0.2.0 的首页与扫描修图模块、0.2.3 的笔记学习工具，以及英文朗读的句级续读与当前句高亮。完整包需要 Gradle 编译扫描模块；手工 javac 打包不包含扫描模块。[标准安装包](dist/Ember-Studio-0.2.7.apk) · [共存安装包](dist/Ember-Studio-0.2.7-parallel.apk)。0.2.7 扩充原创两宋之交剧情「残灯渡」，新增中途抉择和一场遭遇，重绘山道、渡口与敌人形象；失败和撤退重置剧情，经验与成长保留。并支持对已有课堂照片重新处理彩色摩尔纹及对比；对不同图像的效果可能不同。

朗读按句切分，暂停后从当前句附近继续，不再把整段从头重读；播放中当前句只是轻微加深，行高与其余文字不变；暂停位置在切换模式、回到首页再回来之后仍然保留，只有真的改动文本才会清空。高亮默认打开，可在朗读设置里关掉；自动滚动默认关闭。

## 0.2.3：流星与星空水波

0.2.3 在最新学习工具与扫描导出版本基础上，为首页加入跟随流星的星空水波；背景图与动画随包离线提供。

标准包与共存包是独立安装的数据空间；升级前请保留原有应用及数据。签名一致性已核对，实际手机覆盖升级仍待验证。首页使用随包提供的多彩流星背景、柔焦和动态玻璃效果。


- **首页重做**：按「学习 / 创作 / 助手与休息」三组排列八个功能卡片，顶部是问候语和「接着做」卡片。卡片上标着离线、联网、相机等标签，当前设备不能用的功能会直接写明原因。
- **统一的返回机制**：每个功能都登记在 `studio/web/src/back.js` 的模块表里，分成网页模块（同一个 WebView 内切换）和原生模块（独立页面）。返回键一次只关一层：对话框 → 抽屉 → 画画 → 查找 → 模块子层（如 AI 设置、上课时间轴）→ 首页 → 询问退出。原生模块关掉后由宿主发 `moduleReturned`，页面回到首页并更新「接着做」。新功能只需在模块表加一行，再登记自己的子层。
- **扫描文档**：原「扫描相机」2.4.0（Kotlin、CameraX、ML Kit 离线中文 OCR）以 Gradle 库模块 `scan/` 并入，需要 Android 10 及以上和相机。
- **修图**：原「浮生图梦」整套源码放在 `photo/`，新增手机页 `photo/apps/mobile/`，由 `studio/web/build-photo.mjs` 打包到 `studio/src/main/assets/photo/`，宿主是 `PhotoActivity`。导出的图片写进相册 `Pictures/浮生图梦`，ZIP 和工程文件写进 `Download/浮生图梦`。
- **构建**：含扫描模块的完整包用 Gradle 构建：`gradle :studio:assembleDebug`（JDK 17、Android SDK 34）。`tools/build-studio.sh` / `.ps1` 不经 Gradle，打出的包里没有扫描模块，首页会把「扫描文档」标成不可用，其余功能不受影响。

## 数学主题与名字

在城镇点击右侧「主题地图」并选择数学，或沿东边小路走到「数学之门」。学者知夏也会告诉你方向。无需先完成身体主线。探索中从光门或暂停菜单回城，再切换主题；敌人、弹丸和空投会冻结，身体战斗进度保留。

| 地图 | 玩家要做的事 | 首次奖励 |
| --- | --- | --- |
| 等距花园 | 按 ①→②→③ 顺序点亮三盏灯，全程贴着半径 180 的圆（容差 ±18，离轨 0.15 秒即熄灭） | 60 金币、生命上限 +8 |

| 翻向长廊 | 避开两处幻影路标（碰到会抹掉记号），在最多 6 次接缝穿越内点亮三个路标 | 100 金币、生命上限 +8 |

三关依次开放，重复停留、重启或再次进入不会重复领奖。右侧缩略图帮助定位，地面保留近期脚印；「重走」只重置当前未完成机关。已解开的原理在札记中回看。三关现在各有独立的配色主题与动态光效：等距花园是青绿光环与方向箭头，七桥星庭是星夜桥面脉冲与度数标记，翻向长廊是紫罗兰接缝能量带与幻影标记；HUD 会提示下一盏灯、桥数与接缝次数。这些难度约束复用原有存档字段，格式 8 与更旧的存档都能照常读取。长廊是两端反向粘合的理想化接缝模型，箭头表示局部坐标朝向，不表示莫比乌斯带有两张面。

主界面点击「修改名字」：最多 12 个 Unicode 字符，留空恢复「伍子平」。HUD、人物名牌、对话及新旅程沿用所选名字，写入本地存档。

## 天工

天工是可安装的 Android 工作台，不是 VS Code 移植。界面用 CodeMirror 6，Python 用打进 APK 的 Pyodide 0.27.7 / CPython 3.12.7，运行资源都在包内。打开后是首页，点一张卡片就进入；返回键先回到首页，再按一次才询问退出。

| 模式 | 打开之后 |
| --- | --- |
| 写 Python | 多文件编辑，离线运行。工作区自带 `main.py`、`geometry.py`、`data.json`、`index.html`。JavaScript 在独立线程里跑，HTML 有单独的预览页。C/C++、Java、TypeScript 只有高亮 |
| 普通记事本 | 打开 `笔记.txt`，藏起运行、行号和文件标签，草稿仍自动保存。顶栏有画笔；0.1.15 修好了手指画不出笔画的问题 |
| 游戏 | 进入原来的原生画面。《星火远征》存档沿用。游戏里按 Android 返回键可以选择「保存并返回编辑器」；标题界面按返回键直接回编辑器。娱乐区可以导出、导入 `.wzpsave` |
| 上课 | 录音、时间戳笔记和 PPT 照片放在同一条时间轴上。点一行笔记，音频跳到当时，并显示对应的 PPT。详见 `studio/README.md` |
| 英文朗读 | 朗读编辑器里的英文。Android 使用系统 `TextToSpeech`，浏览器里没有这个接口时改用 `speechSynthesis`。长文按句子分段，可以选择已安装的英语语音、调节语速，并暂停、继续或停止 |

上课模式用 WebView 的 `getUserMedia` 和 `MediaRecorder`（webm/opus），单次最长 2 小时。Android 端在第一次录音时申请 `RECORD_AUDIO`。能量 VAD 会自动记语音锚点和沉默锚点，也可以手动「📌 标记锚点」并关联最近一张还没标记的 PPT 照片。照片最长边压到 1024 像素，最多 50 张。0.1.17 源码还可以直接导入 `.pptx`，在页面里逐页画成图片再放进同一照片库；0.1.17 安装包已包含这一项。音频、波形、锚点、照片和笔记时间戳写在工作区 JSON 的 `state.lecture` 里。0.1.13 补上了系统选图（`onShowFileChooser`，`image/*`，可多选）和麦克风权限请求的时机。宿主快照上限仍是 32MB。

英文朗读是启动页上的第五个模式，0.1.15 的两个安装包里都有。手机上由 Android `TextToSpeech` 出声，选择已安装的英语语音，语速在 0.75 到 1.5 倍之间。长文按句子切成小节，可以暂停、继续或停止。同一套页面在浏览器里打开时，改用浏览器的 `speechSynthesis`。新建工作区仍然只有 `main.py`、`geometry.py`、`data.json` 和 `index.html`。进入英文朗读时，如果当时没有可朗读的英文文本，才会创建 `English.txt`；已经存在的工作区文件保持原样。

0.1.15 的界面还包括这些：

- 上课录音栏有一枚「翻译」勾选。勾上或取消都会写入课堂会话，并提示「已开启实时翻译」或「已关闭实时翻译」。它只保存这个开关，没有把语音或笔记送去翻译。

- 启动页是深色的，背景用 CSS 动画画了几道下落的流星。0.1.17 安装包与源码的品牌旁都标着 `0.1.17`。

构建脚本 `tools/build-studio.ps1`（Linux 用 `tools/build-studio.sh`）现在会写出 `dist/Ember-Studio-0.1.17.apk`，共存包是 `dist/Ember-Studio-0.1.17-parallel.apk`，versionName 0.1.17、versionCode 25。0.1.17 的两个包已提交；重新构建会改写 `dist/STUDIO-SHA256SUMS.txt`，需要时记得补回历史版本的校验和。

## 物理工坊

物理工坊在 `PhysicsJourney.java`。中山大学东侧有建筑「格物堂」和物理学者程理（约在 1180, 610）。靠近程理交谈，或站在格物堂（1200, 540）附近点「进入物理工坊」，即可进入。五关依次开放，每关 1536×1152。格物堂面板只展示进度和已发现的原理，不能点选跳关。过关后走到出口，可以选择下一关或回城；没过关也可以从出口回城，当前机关进度会留下。

抛体靶场的角度（20–80°）和力度（20–100）可以在 HUD 上用四个按钮调整，桌面也能按 Z/X 调角度、C/V 调力度；地面虚线实时预览抛物线轨迹。通关对话和格物堂面板会写上该关原理，物理发现另有独立的札记页：工坊内按 L 或点「札记」直接打开，城镇/体内札记右下角也有「物理发现」入口。五关全通后，共振法杖·改会真正收进武库。

| 地图 | 玩家要做的事 | 首次奖励 |
| --- | --- | --- |
| 抛体靶场 | 调整角度与力度，看虚线预览轨迹，走到发射点（300, 800）按操作键发射，依次命中 3 个靶 | 80 金币、生命上限 +10，并恢复 25 生命 |

| 回路工坊 | 在 6 个节点之间按攻击接线，7 条边全部接上即过关 | 140 金币、生命上限 +10，并恢复 25 生命 |

物理进行中，右上角有札记和地图，右下角圆钮是当前关卡的操作键（发射 / 旋转 / 接线 / 推动），桌面也可按 J 或空格；按 L 打开物理发现札记。左下角另有「返回城镇」，直接回到格物堂前；游戏 0.7.1 和天工 0.1.15 都带这颗按钮。

## 横屏与窗口适配

游戏世界按窗口实际宽高填满绘图区，像素保持等比缩放；宽屏扩展水平视野，4:3 平板扩展垂直视野。移动摇杆贴近左下、战斗按钮贴近右下，任务与状态贴近顶部；对话、武库等窗口居中。触控和角色点击采用同一套视口坐标，支持刘海安全边距。

## 武库与战斗玩法

点击左侧「武库」或按 B 打开并暂停战斗。七类武器可以切换（前六类由通关或武器空投解锁，第七类由物理工坊五关全通解锁），拥有各自的普攻范围、速度、倍率、技能与像素图标；Q 快速轮换已解锁武器。旧版体内存档按进度补齐前六类解锁。

| 武器 | 普攻与技能 |
| --- | --- |
| 星火剑 | 均衡扇形斩击，三连击末段增伤；旋刃风暴 |
| 疾风双刃 | 高速近战；突袭位移并获得短时护盾 |
| 血晶长枪 | 长距离窄扇突刺；三束可贯穿弹丸 |
| 脉冲弩炮 | 有飞行时间的远程弹丸；三向齐射 |
| 共振法杖 | 三发扇形法弹；大范围共振震荡 |
| 镇域重锤 | 慢速高伤环形重击；镇域震地攻击和护盾 |
| 共振法杖·改 | 五道扇形法弹，命中后向周围敌人连锁共振；共振连锁齐射 |

每类武器独立强化，最多 +3，花费 30、55、80 金币，每级提高该武器相对基础攻击的倍率。首个武器空投仍保留原有攻击 +4 奖励，同时解锁对应武器。射弹遵守器官墙体、敌人碰撞与穿透次数，并保存飞行状态。

击败敌人积攒爆发能量，满 100% 后点击「爆发」或按 R，造成近域范围伤害并获得 4 秒护盾。护盾减免 55% 伤害；爆发本身击败的敌人不会为本次爆发立即充能。药剂、闪避、升级三选一和原有永久局内成长保留。

## 隐藏相遇：奶龙

奶龙藏在中山大学一处偏僻角落，会沿小范围路径散步、停留；不会预先出现在任务目标、小地图或人物名单中。靠近后它会停下来，玩家可使用交谈按钮、直接点击角色或按 E 开始对话。

先选择愿意坐下来倾听，再在后续对话中给予安慰，完成「角落里的朋友」。玩家可以中途离开、稍后继续，没有惩罚。首次完成获得 **60 金币** 和 **暖心护符：本次旅程生命上限 +15，同时恢复 15 生命**。重复对话、回城、死亡、重启均不会重复发放奖励。成为朋友后奶龙会挥手，并有新的日常台词。

发现后札记才会记录相遇及进度，护符效果在战斗中继续生效。位置、巡游进度、已倾听/已安慰状态保存；开启全新远征才会重置这段相遇及局内成长。对话是本地编写的中文选项剧情，目前没有开放式 AI 聊天。

角色像素素材依据用户提供的奶龙图片，经内置 image_gen 生成，保留透明背景。游戏素材为四帧 64×64 精灵，包含站立、两步行走与开心挥手。[素材与完整生成提示词](docs/NAILONG_ASSET.md)。

## 空投与全身图

每个器官累计第 4 次击败触发药品空投，第 8 次触发武器空投，最终区域的武器阈值为 7。药品与武器各一箱，死亡重试不重置已触发或已领取状态。

空投有落点光圈、降落伞和 2.6 秒下降过程。落地后靠近到 19 世界像素内自动拾取：药品补充一瓶药剂，并直接恢复 25% 生命；武器增加 4 攻击并解锁相应武器类型。空投需要实际拾取，不会在触发时直接到账。满药袋时直接回血仍生效，但不会突破容量上限。

右下角全身病灶图显示红色待净化、金色当前、绿色已净化区域；点击可展开血管路线和副本解锁状态。右上角保留当前器官小地图。全身图、对话、札记和升级选择会暂停战斗。

## 死亡与恢复

死亡弹出 **《病入膏肓》**，显示当前器官、伤害来源、用时和击败数量。选择「回中山大学重整」，重置当前未完成副本的敌人与波次，保留等级、强化、装备、金币、净化记录和奖励归属，恢复生命并至少保留一瓶药剂。正常回城会暂停而不是重置战斗和空投。

## 存档兼容与验证

存档写入格式 8，文件头仍是 `0x575A5052`。加载接受版本 1–8。格式 1–5 沿用原先的字段：旧森林存档继续原剧情；0.3/0.4 已完成五站的体内存档保留金币、护符与旧奖励，并从血管继续新增三站。新旅程保存器官、空投位置和下降时间、装备、净化及奖励状态，以及隐藏伙伴的漫步位置和友情进度。Android 使用原子写入，每五秒、触控状态变化及应用离开时保存。武器解锁、独立强化、爆发能量和友方飞行弹丸也会保存。格式 6 起在这些字段后写入数学机关、领奖状态、名字与特效；格式 7 在数学段和名字之间再写入物理工坊的关卡、领奖和机关状态；格式 8 在物理段末尾追加抛体角度、力度两项，并在武库段追加第七件武器的强化等级。版本号小于 7 时新建一份空的物理进度；小于 8 时发射参数回到 45° / 50、第七件武器强化等级为 0，且物理五关已全通的存档会自动补发「共振法杖·改」。近期脚印和战斗特效为瞬时画面，不进入存档。0.1.13 及更早的天工不能读取格式 8；游戏 0.7.1 与天工 0.1.15 可以。

格式 6 在数学段之后写入名字与特效，加载时物理工坊按未开始处理。格式 7 在数学段和名字之间写入物理工坊，格式 8 的加载顺序与写入一致：数学、物理、名字、特效。`readProfileExtras` 读取名字和特效。游戏回归套件用非默认的数学和物理状态、自定义主角名、特效为 1、自定义发射参数与第七件武器强化等级，检查格式 8 保存、读取、再保存后字节完全一致；格式 6 去掉物理段、格式 7 去掉新增字段并各自改版本号之后，数学、名字和特效照原样恢复，物理进度与发射参数回到初始，格式 7 的全通存档补发奖励武器。0.7.0 说明里「能读取格式 1–5」仍然对得上当前分支。

0.7.0 发布时共 **354 项逻辑检查**（战斗 33 + 城镇剧情 48 + 体内篇 101 + 隐藏伙伴 39 + 扩展 69 + 0.7 专项 64），覆盖实际移动通关、走弦失败、重复桥失败、接缝镜像与朝向、奖励防重复、中途存档续走、双主题切换、旧格式 1–5 迁移、名字与安全区操作。试玩反馈那次提交把套件改到新的按钮位置，并加上 3 项暂停菜单检查，提交说明记为 357 项游戏检查。格式 6、7、8 的存档往返加在 0.7 专项套件里。物理工坊补齐后有独立的 `tools/tests/PhysicsTests.java`，覆盖操作键接通、默认射程命中、角度/力度调节与边界、HUD 按钮与键盘快捷键、镜面/导线机关、物理札记、第七件武器与共振连锁、格式 8 与格式 7 迁移。`tools/verify-release.py` 从 `app/build.gradle` 读取版本，核对当前安装包的校验和、DEX 和资源；它不再把 0.7.0 的 354 项历史日志当成当前套件的通过条件。当前逻辑回归以 `tools/verify-desktop.sh` 和 `tools/verify-studio.sh` 实际跑出来的结果为准。

`artifacts/screenshots-v0.7/` 共 49 张共享 Java2D 渲染预览；39 为扩建东庭，40 为主题选择，41–43 为数学关卡，44 为发现札记，45 为改名，46–49 为挥剑/突刺/挥锤的不同姿态。试玩提交按新按钮重绘过其中若干张。它们是可复现演示状态，不是手机实拍，也没有物理工坊的画面。日志：`artifacts/verification-v0.7.log`、`artifacts/apk-build-v0.7.log`、`artifacts/apk-parallel-build-v0.7.log`。

## 构建与素材

使用 Java 17、Android SDK Platform 34、Build Tools 34.0.0：

```powershell
.\tools\verify-desktop.ps1
.\tools\build-apk.ps1
.\tools\build-apk.ps1 -ParallelInstall
python .\tools\package-source.py
```

Linux 上 `tools/verify-desktop.sh` 对应桌面检查。`tools/build-apk.sh` 的步骤相同，但版本戳还停在 0.7.0 / versionCode 7，输出文件名是 `WuziPing-Emberbound-0.7.0-*.apk`，并会用这些文件重写 `dist/SHA256SUMS.txt`。要得到 0.7.1，用上面的 PowerShell 脚本。可用 `SDK_ROOT` / `JDK_ROOT` 指定工具目录。

天工用 `tools/build-studio.ps1`，Linux 上用 `tools/build-studio.sh`。两个手工脚本从 `studio/build.gradle` 读取 0.2.1 / versionCode 33；它们不编译 Kotlin 扫描模块，完整包请用 Gradle 构建。历史记录：仓库里已提交的仍是 0.1.17 标准包与共存包，0.1.15 的旧包也保留。前端和检查步骤见 `studio/README.md` 的构建一节。

可用 `-SdkRoot` / `-JdkRoot` 指定工具目录。打包复用 `build/manual/debug.keystore`，源码包排除签名私钥、缓存和本地存档。用于真实发布前应配置专门的发布签名。

数学场景通过 `MathRenderer.java` 的绘图接口生成。器官素材通过 `tools/generate_body.py` 用 Pillow 绘制；原有素材生成器为 `generate_assets.py`、`generate_town.py`。原有城镇、战斗贴图和音轨为项目程序绘制/合成；新增奶龙素材。

隐藏伙伴逻辑为 `TownGuest.java`；素材打包脚本为 `tools/pack-nailong.py`。主要体内篇代码：`BodyJourney.java`（副本/剧情/奖励/空投）、`BodyRenderer.java`（体内场景与全身图）、`BodyNavigation.java`（器官地图寻路）。物理工坊在 `PhysicsJourney.java`，城镇入口在 `Town.java` 与 `Story.java`。战斗粒子、震屏和拖尾在 `Vfx.java`，不进入存档。历史设计见 `docs/DESIGN.md`，0.7.0 的变更见 `docs/UPDATE_0.7.md`，武库记录见 `docs/UPDATE_0.5.md`。
